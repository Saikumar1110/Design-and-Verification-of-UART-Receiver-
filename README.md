# Design-and-Verification-of-UART-Receiver-

This project implements a UART (Universal Asynchronous Receiver-Transmitter) using Verilog HDL. UART is a serial communication protocol used to exchange data between two devices without requiring a shared clock. The design consists of separate transmitter and receiver modules, integrated through a top-level module. The transmitter converts 8-bit parallel data into serial data, transmitting it in the standard UART frame format consisting of one start bit, eight data bits (LSB first), and one stop bit. Similarly, the receiver detects the incoming start bit, samples the eight data bits, and reconstructs the original parallel data.

The transmitter and receiver are controlled using finite state machines (FSMs), while a baud rate generator produces separate timing-enable signals for transmission and reception. The transmitter uses states such as IDLE, START, DATA, and STOP to manage the transmission process. The receiver uses a two-stage synchronizer to reduce metastability risks when sampling the asynchronous serial input, followed by start-bit validation and data sampling. In addition to the integrated UART implementation, a separate parameterized UART receiver is developed using a configurable clocks-per-bit value, allowing the receiver to support different baud rate configurations.

The design is verified using Verilog testbenches that simulate serial data transmission and reception under different operating conditions. The verification includes transmitting and receiving sample bytes, checking the reconstructed parallel data, monitoring transmitter busy status, and validating the receiver data-ready signal. A separate testbench for the parameterized receiver verifies the reception of multiple UART data frames and checks the number of successfully received bytes. This project provides practical experience with serial communication protocols, FSM-based RTL design, baud rate generation, asynchronous input synchronization, parameterized Verilog modules, and functional simulation.
